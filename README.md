# To Do List

A personal to-do list: three fixed categories (Work, Business, Other), each holding
sub-categories you create (e.g. "Screening V2 config"), each holding activities you tick off.
When every activity in a sub-category is ticked, the sub-category is struck through.

- `frontend/` — React 19 + Vite + Tailwind v4, deployed as Cloudflare Workers static assets
- `api/` — Cloudflare Worker + Neon Postgres

See [CLAUDE.md](CLAUDE.md) for setup, development, testing and deployment.
